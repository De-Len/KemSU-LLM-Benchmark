# LLM Benchmark for Kemerovo State University (KemSU)

![Tests](https://img.shields.io/badge/tests-20%20dialogues-brightgreen.svg)

Фреймворк для тестирования и сравнения локальных больших языковых моделей (LLM) в задаче вопросно-ответной системы с использованием RAG (Retrieval-Augmented Generation). Разработан специально для чат-бота Кемеровского государственного университета, который будет работать полностью локально на серверах вуза.

## 📌 О проекте

В КемГУ планируется запуск собственного чат-бота на основе LLM, который поможет студентам и сотрудникам получать ответы на вопросы об учебном процессе, расписании, документах и контактах. Ключевые требования:
- **Полная локальность** — все данные остаются на серверах университета
- **RAG-архитектура** — ответы генерируются только на основе предоставленных чанков из базы знаний
- **Высокая точность** — недопустимость галлюцинаций в образовательной среде
- **Низкая задержка** — ответ должен приходить менее чем за 2 секунды

Данный репозиторий содержит фреймворк для объективного сравнения LLM по математическим метрикам и выбора оптимальной модели для production-развертывания.

## 🖥️ Тестовое оборудование

Все замеры проводились на следующей конфигурации:

| Компонент | Характеристики |
|-----------|----------------|
| **CPU** | Intel Core i9-13900K |
| **GPU** | NVIDIA RTX 5090 (32 ГБ VRAM) |
| **RAM** | 64 ГБ DDR5 (5200 МГц) |

> ⚠️ Результаты latency могут отличаться при развертывании на другом оборудовании. Более слабая видеокарта увеличит время ответа, более мощная — позволит снизить задержки или запускать модели большего размера.

## 📊 Метрики

Фреймворк вычисляет следующие метрики для каждого ответа:

| Метрика | Описание | Целевое значение |
|---------|----------|------------------|
| **F1** | Гармоническое среднее между точностью и полнотой (BERTScore) | выше → лучше |
| **token_f1** | Жесткое совпадение слов на уровне токенов | выше → лучше |
| **keyword_coverage** | Доля ключевых фраз из эталона | выше → лучше |
| **number_match** | Точность совпадения чисел (телефоны, индексы, кабинеты) | 1.0 = идеально |
| **perplexity** | Уверенность модели в ответе | ниже → увереннее |
| **semantic_entropy** | Разнообразие смыслов, а не токенов | интерпретируется в контексте |
| **latency_sec** | Время генерации ответа в секундах | ниже → лучше |
| **distinct_1/distinct_2** | Уникальность лексики | 1.0 = все слова уникальны |

### Как интерпретировать метрики

| Сценарий | Perplexity | Entropy | F1 | Причина |
|----------|------------|---------|-----|---------|
| Хороший ответ | низкая | низкая | высокий | Модель уверена и точна |
| Галлюцинация | низкая | низкая | низкий | Модель уверена, но не права ⚠️ |
| Неуверенный ответ | высокая | высокая | любой | Модель сомневается |
| Многословный ответ | низкая | средняя | высокий Recall | Модель перечисляет лишнее |
